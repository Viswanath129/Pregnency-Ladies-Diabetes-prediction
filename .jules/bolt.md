## 2024-05-17 - FastAPI + Scikit-Learn Inference Bottlenecks
**Learning:** Instantiating `pandas.DataFrame` and making CPU-bound model inferences inside FastAPI's `async def` endpoints block the event loop, causing severe latency under load. Single-row inferences using scikit-learn models are significantly slower when passed a `DataFrame` compared to a raw 2D `numpy.array`.
**Action:** Always use standard `def` for FastAPI endpoints performing CPU-bound work (like ML inference) so they run in external thread pools. For single-row predictions, bypass `pandas.DataFrame` and use 2D `numpy.array`, cleanly suppressing `UserWarning` regarding missing feature names using `warnings.catch_warnings()` and explicitly casting outputs to standard Python scalar types (e.g. `float`) to avoid serialization errors.
