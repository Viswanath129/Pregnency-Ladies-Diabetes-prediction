## 2024-05-18 - Single-Row Inference Overhead with Pandas
**Learning:** Instantiating `pandas.DataFrame` for single-row feature vectors in the ML pipeline introduces significant overhead compared to raw `numpy` arrays. Additionally, using NumPy scalar functions (`np.clip`, `np.std`, `np.random.normal`) for single values is much slower than using pure Python equivalents (`min`/`max`, standard math, `random.gauss`). Finally, synchronous ML inferences within an `async def` FastAPI route block the main event loop, reducing concurrency.
**Action:** Use 2D `numpy.array` wrapped in `warnings.catch_warnings()` for scikit-learn single-row inferences to bypass DataFrame overhead while suppressing feature name warnings. Replace scalar NumPy operations with pure Python math in hot paths. Declare CPU-bound FastAPI routes with standard `def` instead of `async def` to offload work to an external thread pool.
