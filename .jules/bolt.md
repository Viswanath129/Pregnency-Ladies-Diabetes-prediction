## 2024-05-18 - [FastAPI & Scikit-Learn Fast Loop Optimization]
**Learning:** Using `pandas.DataFrame` instantiation and NumPy functions (like `np.clip`, `np.std`, `np.random.normal`) for single-row inference introduces significant latency overhead due to heavy Python object creation and C-extension boundary crossings.
**Action:** Always bypass `pandas.DataFrame` by using 2D `numpy.array` inputs for single-inference ML pipelines, explicitly cast NumPy scalar outputs to native `float()` types, and replace NumPy statistical/math operations with pure Python equivalents (`min`, `max`, `random.gauss`, `math.sqrt`) when processing scalars or small arrays in high-throughput endpoints. Additionally, use `def` instead of `async def` for CPU-bound ML inferences in FastAPI to leverage external thread pools.
