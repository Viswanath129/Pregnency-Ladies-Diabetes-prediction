## 2024-05-18 - [FastAPI Endpoint Inference Optimization]
**Learning:** scikit-learn models trained on `pandas.DataFrame`s log UserWarnings if inference is performed using `numpy.array` lacking feature names. While `numpy.array` inference is noticeably faster for single-row inputs than DataFrame construction, the warnings can clutter logs. Furthermore, NumPy float types (`numpy.float64`) returned by inference might not be cleanly serializable by standard JSON responses.
**Action:** Use `numpy.array` instead of `pandas.DataFrame` for single-row inference in high-performance contexts. Wrap the `predict` calls in `warnings.catch_warnings()` with `warnings.simplefilter("ignore", UserWarning)` to suppress missing feature names warnings. Also, always explicitly cast numerical outputs back to standard Python `float()` to ensure JSON serializability.
