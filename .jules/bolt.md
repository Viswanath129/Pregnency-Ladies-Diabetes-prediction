## 2024-03-01 - Avoid Pandas DataFrame and Numpy Overheads in Hot Loops
**Learning:** During backend ML inference inside a FastAPI route, creating `pd.DataFrame` and using `np` primitives (like `np.random.normal`, `np.clip`, and `np.std`) for very small scalar inputs adds immense latency per-request. Also, using `async def` for CPU-bound tasks like ML inference blocks the asyncio event loop and kills concurrent throughput.
**Action:** When working on single-row model inferences, wrap the raw array using `np.array()` directly and bypass `pd.DataFrame`. Replace small numpy vector calculations with standard pure-Python math functions (e.g., `random.gauss`, manual variance calculation). Most importantly, keep CPU-bound routes as standard `def` (instead of `async def`) so FastAPI routes them to an external thread pool automatically.
