## 2024-05-18 - [FastAPI Backend Performance Optimization]
**Learning:** In fast API loops, replacing NumPy functions (`np.std`, `np.clip`, `np.random.normal`) with their pure Python equivalents (manual variance calculation, `min`/`max`, and `random.gauss`) can yield a significant performance boost. NumPy functions have non-trivial overhead when called repeatedly for single scalar values or very small arrays. Replacing a `pd.DataFrame` creation with a simple `np.array` list wrapping also saves time and gets rid of Pandas dependency. Additionally, changing `async def predict_risk` to `def predict_risk` prevents blocking the main event loop since ML inference is CPU-bound.
**Action:** When doing operations on scalar values or small datasets inside high-throughput handlers (e.g. 100 requests per second), prefer Python built-ins over generic numerical library functions. Also ensure endpoints doing heavy CPU tasks are run in an external thread pool by using `def` instead of `async def`.
