
## 2023-10-25 - Python Scaler Operations & Single Row Inference
**Learning:** For single-row model inferences, creating `pandas.DataFrame` objects introduces massive overhead compared to using raw `numpy.array`. However, even `numpy` scalar functions (like `np.std`, `np.clip`, `np.random.normal`) incur significant array-conversion overhead for pure scalar operations, making pure Python implementations (`math.sqrt`/`min`/`max`/`random.gauss`) substantially faster. Additionally, `async def` on CPU-bound FastAPI routes (like ML inference) blocks the event loop, so `def` should be used to enable threadpool execution.
**Action:** When optimizing hot paths or fast API loops for single row inference: 1) Skip pandas entirely and use 2D numpy arrays. 2) Wrap scaler transforms in `warnings.catch_warnings()` to suppress `UserWarning` for missing feature names. 3) Replace numpy math for scalar values with Python's built-in `math` and `random` modules. 4) Use `def` instead of `async def` for CPU bound inference endpoints.
