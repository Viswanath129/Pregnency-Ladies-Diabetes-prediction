## 2025-05-23 - Optimizing ML inference single-row predictions
**Learning:** Instantiating `pd.DataFrame` and passing it to scikit-learn for single-row inference adds considerable overhead (~20-25% time penalty). Passing a 2D numpy array directly `np.array([vitals])` removes this instantiation overhead and speeds up the endpoint. However, it generates a `UserWarning` about missing feature names (since models were fitted with DataFrames), which can be silenced using `warnings.catch_warnings()`. Note that explicitly casting numpy scalar outputs (`float()`) ensures JSON serialization works cleanly in FastAPI and avoids numpy type bleed.
**Action:** Use `np.array()` instead of `pd.DataFrame()` for low-latency, real-time, single-row scikit-learn predictions in web APIs, wrapping the inference call with a warnings filter to keep logs clean.
