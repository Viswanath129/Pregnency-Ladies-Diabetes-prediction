## 2024-05-18 - Fast FastAPI Inference
**Learning:** For CPU-bound ML model inference (like scikit-learn models), using `async def` in FastAPI blocks the main event loop, severely degrading concurrent request handling. Additionally, creating a full `pandas.DataFrame` for single-row inference adds significant overhead compared to using a 2D `numpy.array`. However, passing a numpy array to a model trained with pandas will trigger noisy `UserWarning`s about missing feature names.
**Action:** Always use standard synchronous `def` for FastAPI endpoints performing CPU-bound ML inference so it runs in an external thread pool. For single-row predictions, construct a 2D `numpy.array` and wrap the inference call in `warnings.catch_warnings()` to suppress the feature name warnings. Finally, explicitly cast the numpy scalar outputs to standard Python `float()` for type safety and serialization.
