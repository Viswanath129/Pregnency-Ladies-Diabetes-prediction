## 2024-07-04 - CPU-bound ML Inference in FastAPI & NumPy vs Pure Python Scalar Ops
**Learning:** In FastAPI, running CPU-bound scikit-learn models inside an `async def` endpoint blocks the main event loop, significantly degrading concurrency. Also, calling NumPy functions (`np.clip`, `np.std`, `np.random.normal`) or instantiating pandas DataFrames for single rows or scalar values introduces massive overhead (up to ~10-25x slower than pure python `math`/`random` modules and `np.array`).
**Action:** Always use synchronous `def` for FastAPI endpoints performing heavy ML inference to leverage the external thread pool. For single-row inferences, strictly bypass pandas `DataFrame` and use 2D `numpy.array`. For operations on scalars or very small arrays (size < 10) in hot paths, replace NumPy functions with standard library modules like `math` and `random` to eliminate C-extension call overhead.
